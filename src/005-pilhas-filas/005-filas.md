# Filas

É uma estrutura de dados linear que segue a ordem de operação FIFO.
First in, First out.

## Operações
- add: Adiciona um elemento no final da fila.
- remove: Remove o elemento do início da fila.
- peek: Retorna o elemento do início da fila sem removê-lo.
- isEmpty: Verifica se a fila está vazia.
- count: Retorna o número de elementos na fila.
- isFull: Verifica se a fila está cheia (em implementações com capacidade limitada).
- isEmpty: Verifica se a fila está vazia.
